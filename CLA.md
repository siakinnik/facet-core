## 9. How to sign

When You open your first pull request, a bot asks You to sign. Post this
comment in the pull request:

> I have read the CLA Document and I hereby sign the CLA

Your GitHub user name, the time and the pull request are recorded. Signing once
covers all your later Contributions to all Facet projects; the bot keeps its
records per repository, so in another Facet repository it may ask You to post
the comment again. If the Maintainer
publishes a new version of this agreement, Contributions that You submitted
under this version stay under this version.
